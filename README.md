# jeandevel.github.io

Mi página personal, hecha con **HTML y CSS** mientras aprendo desarrollo web. La voy ampliando poco a poco.

🌐 **Sitio en vivo:** [jeandevel.github.io](https://jeandevel.github.io)

## 📋 Qué tiene por ahora

- Una cabecera con mi foto de perfil en círculo, mi saludo y una breve presentación.
- Diseño adaptado a pantallas de celular.

## 📂 Estructura del proyecto

```text
jeandevel.github.io/
├── index.html    # Contenido y estructura de la página
├── style.css     # Estilos y diseño
└── img/          # Imágenes del sitio
```

## 🚀 Cómo verlo en tu computadora

1. Descarga o clona el repositorio:

   ```bash
   git clone https://github.com/jeandevel/jeandevel.github.io.git
   ```

2. Abre `index.html` en tu navegador, o usa la extensión **Live Server** de VS Code.
